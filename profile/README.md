## How this page updates itself

`scripts/generate_cards.py` calls the GitHub API for this org's
public repos, renders a branded SVG card per repo plus the banner
above, and rewrites the block between `PROJECTS:START` /
`PROJECTS:END`. A scheduled GitHub Action
(`.github/workflows/update-readme.yml`) runs it daily and on every
push to `main`, committing back only when something actually
changed.

To regenerate locally:

```bash
GITHUB_TOKEN=<token> python scripts/generate_cards.py --org ulite-team
```
